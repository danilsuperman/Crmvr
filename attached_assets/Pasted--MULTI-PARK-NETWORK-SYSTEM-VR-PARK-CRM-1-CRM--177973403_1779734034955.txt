# ТЗ: MULTI-PARK / NETWORK SYSTEM ДЛЯ VR PARK CRM

# 1. ОБЩАЯ ИДЕЯ

CRM должна поддерживать:

* несколько VR-парков,
* несколько арен,
* франшизы,
* сети парков,
* отдельные локации.

---

# СУТЬ АРХИТЕКТУРЫ

Один аккаунт владельца может содержать:

```plaintext id="parks"
• VR Park Moscow
• VR Park Dubai
• Arena CyberZone
• Kids VR Arena
```

Каждый парк:

* полностью изолирован,
* имеет свои:

  * брони,
  * устройства,
  * игры,
  * сотрудников,
  * аналитику,
  * настройки.

---

# Но:

владелец может видеть:

# ОБЪЕДИНЕННУЮ СЕТЕВУЮ АНАЛИТИКУ
